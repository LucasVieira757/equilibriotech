PERGUNTAS FREQUENTES

É mais simples do que parece.

Sem prometer milagres — e sem vender ferramentas que você não precisa.

Preciso mudar meu sistema ou deixar de usar Excel?

Não necessariamente. Nosso foco inicial é melhorar processos existentes. Avaliamos seus arquivos e ferramentas antes de recomendar qualquer mudança.

Uma automação serve para uma empresa pequena?

Sim, quando existe uma tarefa repetitiva com regras claras e ganho suficiente para justificar o investimento. Uma rotina simples costuma ser um ponto de partida melhor que um projeto enorme.

Vocês precisam acessar dados confidenciais?

Não para uma conversa inicial. Podemos avaliar o processo com dados fictícios ou anonimizados. Se um projeto exigir acesso real, alinharemos permissões, segurança e tratamento de dados antes.

Quanto custa?

O preço depende da complexidade e do tempo de execução. Primeiro entendemos uma rotina concreta e depois apresentamos o valor e o escopo de um piloto, sem obrigação de contratar.

TRANSPARÊNCIA

Como usamos os dados do formulário

Solicitamos nome, empresa, e-mail, serviço de interesse, descrição do problema e, opcionalmente, telefone. Usamos essas informações para responder ao contato e avaliar uma possível prestação de serviços. Não pedimos planilhas reais nesta etapa.

Após ativado, o formulário envia os dados ao Formspree, provedor terceirizado responsável pelo recebimento e encaminhamento. Os dados podem permanecer na conta do provedor de acordo com suas configurações e políticas. Para pedir esclarecimentos, correção ou exclusão de informações, escreva para lucasvst91@gmail.com.
